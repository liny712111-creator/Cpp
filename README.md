# Cpp 作业

本仓库按章节整理了两次 C++ 作业：

- `Chapter3/`：第三章类练习，题目 3.11、3.14、3.15。
- `Chapter4/`：第四章练习，题目 4.15、4.26、4.27、4.33。

每题各自放在一个文件夹中，程序入口为 `main.cpp`。

4.15（Sales Commission Calculator）文件夹中的 `pseudocode.txt` 保存本题伪代码。

- `Chapter5/`：第五章练习，题目 5.5、5.12、5.15 和 5.20。
  - 5.20 保留两种边顺序的写法；5.12 包含分开输出和并排输出两个版本。
- `Chapter6/`：第六章练习，题目 6.29、6.30、6.37 和 6.41。
  - 6.29 保留试除到 n/2 与根号 n 两种判定函数，在主程序里切换注释即可。
- `Chapter7/`：第七章练习，题目 7.11、7.12、7.15 和 7.36。
  - 7.11 为基础版冒泡排序，每轮固定比较 9 次；7.12 同时包含逐轮减少比较次数和提前终止两个优化。
  - 7.15 用长度为 20 的数组存放去重结果，先校验 10~100 范围，再判断是否与已存数字重复。
  - 7.36 用递归实现逆序打印：递归到字符串末尾后回溯输出字符。
